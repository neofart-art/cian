- `python -m pytest -q`: **19 тестов прошли**. Включены точный формат `url;title;price;area;card_text`, пустой title, цены с ₽, площади с десятичной запятой, BOM/UTF-8/UTF-16/Windows-1251, разные разделители, многострочный текст, извлечение адреса/этажа/метро/пешего времени, различение пешком/транспортом, повторы в файле, обновление существующих записей, сохранение первой даты и старых объявлений, повторное/просроченное/отменённое подтверждение, защита авторизацией и Origin, отсутствие частичных изменений при ошибке. Миграция исходной схемы БД и повторный запуск проверены на временной БД.
- Независимость импорта от сети проверена в тестах с блокировкой HTTPTransport и в настоящем контейнере с `--network none`: предпросмотр, подтверждение, SQLite, XLSX работают; запись сохраняется после рестарта.
- Настоящий Chromium/Playwright: выбор `cian_favorites_test.csv`, число строк до сохранения, подтверждение, отображение полей, предпросмотр повторного импорта, отмена, ошибка файла без URL; нет ошибок JavaScript. Просмотрены desktop и mobile (390 px) снимки.
- `node --check app/static/app.js`, `git diff --check`: успешно.
- Docker-проверка использовала те же закреплённые зависимости и временный offline build-контекст с заранее скачанными по HTTPS колёсами, как описано ниже. Финальные уточнения нормализации времени и адреса дополнительно проверены тестами; обычная сетевая сборка на OMV не выполнялась.
- CAPTCHA — штатный `blocked` для онлайн-сбора, приложение остаётся healthy, CSV доступен. Обход защиты не реализован.
- Проверен формат и примеры, описанные пользователем; реальный полный файл пользователя не предоставлялся. Разбор свободного `card_text` приблизительный, исходный текст сохраняется. Реальный онлайн-сбор по-прежнему не подтверждён.

## Проверки первой версии

- `python -m pytest -q`: 2 теста прошли. Проверены парсер на искусственном JSON-LD, ошибка неподдерживаемого HTML/CAPTCHA, Basic Auth, Origin, валидация фильтров, сохранение результата, ограничение частоты, XLSX и защита от Excel-формул, сохранение старых результатов при ошибке источника.
- `node --check app/static/app.js`: успешно.
- `docker compose -p xata config --quiet` с временными тестовыми значениями переменных: успешно.
- Реальный HTTP-запуск Uvicorn: интерфейс, состояние, healthcheck и XLSX проверены.
- Обычный `docker build` остановился на сетевой недоступности PyPI внутри build-контейнера облачной среды. Для проверки исполнения создан временный build-контекст вне репозитория: те же зависимости скачаны с PyPI с обычной проверкой TLS, установка заменена на offline `--no-index --find-links`. Dockerfile проекта не изменён этой проверкой.
- Контейнер из временного контекста успешно запущен с UID 10001, read-only root, tmpfs, отдельным volume, лимитом памяти 384 МБ, CPU 1, без capabilities. HTTP-проверки интерфейса, SQLite, healthcheck, Excel и повторного запуска прошли. Тестовый контейнер и volume удалены.
- Циан из облачной среды вернул HTTP 302 на `/tmgrdfrend/showcaptcha`. Работа парсера с реальной выдачей не подтверждена. Тестовые объявления в рабочую базу не добавлялись.
- На OMV приложение не устанавливалось. DNS, NPM, HTTPS, привязка к 172.31.1.1 и реальное получение объявлений на пользовательском сервере ещё не проверены.
